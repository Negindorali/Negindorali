### About me

I've been building production web apps since 2018. Most recently I worked on an **Industrial IoT platform**, building the dashboards, SCADA process diagrams and map views that operators use to monitor sensors in factories and greenhouses.

Working that close to sensor data got me interested in what happens *before* the dashboard. That's why I'm now moving into **data engineering**, and doing my M.Sc. in AI on it.

- 🎓 **Thesis:** a lightweight smart-filtering layer at the network edge that feeds a real-time Feature Store (`Edge → MQTT → Kafka → Feast`). In my prototype it cuts the data sent to the cloud by **96%** while keeping **100%** of the anomalies.
- 🏗️ **Currently building:** *Nabz-e Shahr (City Pulse)*, a streaming + batch platform on NYC taxi trip data (~19.6M trips/month).
- 🌱 **Learning:** Kafka / Redpanda, Spark, Airflow, dbt, Apache Iceberg, data quality & data contracts.
- 💼 **Background:** Vue.js, React, Nuxt and micro-frontend architecture (single-spa, RxJS) across 5 companies and 15+ shipped products.
